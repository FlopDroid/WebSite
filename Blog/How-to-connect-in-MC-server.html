FlopDroid

Πως συνδέομαι στον Minecraft Server;

Απρ. 18, 2025 Συνδεσιμότητα, Minecraft, Mojang Minecraft, TL Minecraft

Για να συνδεθεί κανείς στον Minecraft Server της FlopDroid χρειάζεται να πληροί όλες τις βασικές απαιτήσεις που έχει κάθε server.

Απαιτήσεις

  • Σύνδεση στο διαδίκτυο
  • Σύνδεση στο ZeroTier (προαιρετικό)
  • Mojang Minecraft ή TLauncher
  • Την ip/domain του server
  • Αν ο server είναι με mods να έχει το mod pack
  • Αν ο server δεν κατεβάζει αυτόματα το resource pack να έχει το resource pack

Έχοντας τα παρακάτω μπορεί να μπει ο καθένας δίχως κάποια δυσκολία στον server. Όμως θα χρειαστεί να υπάρχει εγκατεστημένη η σωστή έκδοση του Minecraft (δεν έχει να κάνει με Mojang ή TL). Για παράδειγμα ο server μπορεί να είναι στην έκδοση 1.20. Ως χρήστης θα χρειαστεί να έχεις εγκατεστημένη την έκδοση 1.20 (δεν παίζει ρόλο αν είναι optifine). Μετά επειδή οι περισσότεροι servers είναι με plugins εισάγοντας το domain flopdroid.ddns.net στο «Add Server» (το «Server Name» δεν επηρεάζει την σύνδεση) ή στο «Direct Connection» θα συνδεθεί η συσκευή στον server. Φυσικά για να γίνει η σύνδεση θα πρέπει να είναι ανοιχτός και ο server. Υπάρχουν 2 τρόποι σύνδεσης στον server. Ο πρώτος είναι μέσω του port forwarding όπου για εσένα που είσαι απλός χρήστης του server θα εισάγεις το domain/ip του FlopDroid Server. Ο δεύτερος τρόπος είναι μέσω του ZeroTier που έχει γίνει σχετικό άρθρο για αυτό.

Εδώ τελειώνει και το άρθρο για την σύνδεση στον Server. Προς το παρόν δεν υποστηρίζεται η Bedrock έκδοση του Minecraft οπότε μόνο μέσω της Java Version μπορεί να μπει κανείς.

Φυσικά για τυχόν προβλήματα με την διαδικασία του join και γενικά ότι έχει να κάνει με τον server θα μας βρείτε στο Discord.
